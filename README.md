# Floodline

Самостоятельная соревновательная змейка на Go для Duels, Standard, Royale и Constrictor. Каждый ход рассчитывается из состояния, присланного ареной. Для игры нужны только процессор и сеть.

## Запуск

С Go 1.23 или новее выполнить в корне репозитория:

```sh
go run .
```

По умолчанию сервер слушает порт 8080. Переменная `PORT` задаёт другой порт. Проверка метаданных — `curl http://127.0.0.1:8080/`. Сервер принимает `POST /start`, `POST /move` и `POST /end`.

Для запуска в Docker на одном ядре:

```sh
docker build -t floodline .
docker run --rm --cpuset-cpus=0 --cpus=1 -e GOMAXPROCS=1 -p 8080:8080 floodline
```

## Пример локальной дуэли

Пока первый сервер работает на порту 8080, запустить собственного тренировочного соперника в другом терминале:

```sh
PORT=8081 STYLE=food go run .
```

В третьем терминале установить и запустить официальный движок фиксированной версии:

```sh
go install github.com/BattlesnakeOfficial/rules/cli/battlesnake@v1.2.3
"$(go env GOPATH)/bin/battlesnake" play -W 11 -H 11 -g standard -m standard --seed 42 --timeout 500 \
  --name Floodline --url http://127.0.0.1:8080 --name Forager --url http://127.0.0.1:8081
```

Режимы `food`, `space`, `press` и `baseline` выбирают разные учебные стратегии. Вариант `baseline` учитывает свободную территорию, ловушки, достижимость еды с поправкой на здоровье, опасные клетки и угрозы от головы противника.

## Публикация

Подключить этот репозиторий как сервис Railway. Конфигурация задаёт Dockerfile, одну реплику в Амстердаме, проверку `GET /` и постоянно работающий процесс. В настройках сети нажать **Generate Domain**. Зарегистрировать полученный HTTPS-адрес в Battlesnake, выбрать европейский регион и присоединить одну змейку к каждому из четырёх рейтингов. При `CAPTURE_SAMPLES=1` в лог попадает первый стартовый запрос каждого сочетания карты, правил и числа участников.

Спецификация доступна в [документации Battlesnake](https://docs.battlesnake.com/api/webhooks). Симулятор и стратегии Floodline написаны самостоятельно. Официальный [Battlesnake Rules v1.2.3](https://github.com/BattlesnakeOfficial/rules/tree/v1.2.3) используется для проверок и тренировочных партий.
