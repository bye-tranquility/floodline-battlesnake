## Три сетевых тайм-аута

Арена зарегистрировала 500 мс на 9-м ходу выигранной дуэли и на 60-м и 137-м ходах против DenoM. При разборе первого события в соответствующем интервале Railway нашлось 39 ответов HTTP 200 с максимумом 46 мс. В двух интервалах DenoM нашлось по одному HTTP 499 с закрытием запроса клиентом, максимальная длительность запросов составила 28 и 27 мс. Причину сетевой задержки по этим данным установить не удалось. [Выигранная дуэль](https://arena.battlesnake.com/games/a80239e1-37b9-43c6-b824-a5144afd36f8) · [Дуэль с DenoM](https://arena.battlesnake.com/games/566128c6-3ae1-45d8-950d-a7c98dbd9fc3)

Образ v0.13.0 получил 1 000 полных HTTP-запросов на девяти позициях вокруг этих трёх ходов. Контейнер был привязан к CPU 0 с квотой в одно ядро и `GOMAXPROCS=1`. На 500 последовательных запросах p99 составил 8,451 мс. На 500 запросах с четырьмя одновременными играми p99 составил 32,915 мс. Максимум — 90,997 мс.
